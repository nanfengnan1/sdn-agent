# Agent 待解决问题

统一跟踪清单：[跨项目待解决问题与修复任务](../../sdn-controller/docs/backlog.md)。

Agent 已通过 Redis（需 AOF/持久卷）或 fsync 文件日志保存任务、Undo、配置记录和幂等收据，并在状态目录保存身份；缺失的是完整的主机/网络命名空间重建后网络配置恢复，不是所有数据都没有持久化。

优先跟踪 REL-003（回滚恢复流程）、REL-004（重建后恢复实际网络）、REL-005（漂移核对）、REL-006（存储异常）、REL-007（日志归档）和 REL-009（管理代次隔离）。当前 Agent 重启不会自动重放全部 Linux 配置，不能仅凭旧 Running revision 判断网络已恢复。

## 1. 数据恢复后的配置自动重建（未实现，REL-004）

身份、配置记录和事务日志恢复后，Agent 尚不会自动核对 Linux/FRR 实际状态并重新下发缺失或不一致的有效配置。宿主机、容器网络命名空间重建或后端配置丢失时，持久化数据恢复不保证业务网络恢复。

当前行为、恢复边界、待实现流程和验收要求统一维护在 [REL-004 详情](../../sdn-controller/docs/backlog.md#rel-004)。
